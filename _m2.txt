fix: three regressions the tier 4+5 gate found in the tier 4+5 fixes

The silence detector became CUMULATIVE. Requiring a sustained burst to clear
the counter meant a burst that never reached 0.30s cleared nothing, so every
gap was banked across the whole session -- someone reading a list aloud was cut
off 122 seconds into an active dictation, and ordinary speech with 50ms
stop-consonant closures at 450 seconds.

Burst length was the wrong discriminator entirely, and measuring it says so:
real words are SHORT (a list read aloud is 0.25s on, 0.70s off) while room
noise can be LONG (a door is 350ms). So the sustained-burst rule cut off the
speaker AND let the empty room run for an hour -- both promises broken by the
thing meant to fix one of them.

Duty cycle separates them cleanly. Speech is a quarter to four fifths voiced;
a room with an occasional noise is well under one percent. Any sound now clears
the continuous-silence counter, as it did before, and a decaying average of how
much of the recent past carried sound catches the forgotten session. Verified
against seven measured patterns: four speech shapes run 900s untouched, three
empty-room shapes stop within 200s, and a genuinely silent room still stops on
the original condition at 90s.

Stopping the overlay's timer at rest broke two things that depended on that
clock:

- "off" was the one path that changes state without restarting the timer, so
  the fade never ran and a translucent always-on-top capsule stayed on the
  bezel permanently. Pausing the hotkeys from the tray hits exactly this.

- The adaptive gain decays only in the idle paths, which run on the timer that
  now stops -- so after a loud dictation it froze at whatever that left and the
  next session's first word read low. That is precisely the failure the decay
  was added for. It now forgets outright when the clock stops, since a decay
  measured in frames has no clock to run on.
