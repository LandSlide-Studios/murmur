# Adversarial scenarios

Written air-gapped: each author worked from the module's own contract and from
first principles, without the engineering log, the locked-decision list, or the
existing tests. The point is to not inherit the blind spots of whoever wrote the
code.

That means a failure in here is a *claim*, not a verdict. Every one gets triaged
against the design record as a true or false positive before anything is changed.
